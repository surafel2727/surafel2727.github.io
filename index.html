03.

project

🔎 NetScan — Python Network Scanner FEATURED
↗ github

A lightweight network scanner built entirely in Python's standard library — no external packages required. Discovers active hosts on a network, identifies open ports, resolves hostnames via reverse DNS, and exports timestamped scan reports. Built to understand how tools like Nmap work under the hood.

  • TCP-based host discovery — detects online devices without requiring root/ICMP ping
  • Scans 15 well-known ports (HTTP, SSH, FTP, RDP, MySQL, etc.) per host
  • Reverse DNS resolution — maps IP addresses to device hostnames
  • Multi-threaded scanning with Python's concurrent.futures for parallel execution
  • Supports single IPs and CIDR ranges (e.g. 192.168.1.0/24)
  • Saves full results to a timestamped report file automatically
  • 200+ lines, fully documented — every function and concept explained in comments
Python 3.8+ socket ipaddress threading TCP/IP DNS CIDR Kali Linux
