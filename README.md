## ✨ Features

- Terminal/hacker aesthetic — dark green-on-black theme inspired by Kali Linux
- Fully responsive — works on mobile, tablet, and desktop
- Scroll-triggered animations — elements fade up as you scroll
- Animated skill bars — fill on scroll into view
- Smooth navigation — single-page with anchor scroll
- Zero dependencies — pure HTML, CSS, and vanilla JavaScript
- No build tools needed — just open `index.html`

## 🚀 Run Locally

No installation required. Just clone and open:

```bash
git clone https://github.com/surafel2727/surafel2727.github.io.git
cd surafel2727.github.io
# Open index.html in your browser
```

Or with Python's built-in server:

```bash
python3 -m http.server 8080
# Then visit http://localhost:8080
```

---

## 🌐 Deploy to GitHub Pages

1. Create a repository named exactly `surafel2727.github.io`
2. Push `index.html` to the `main` branch
3. Go to **Settings → Pages → Source → main branch**
4. Site will be live at `https://surafel2727.github.io`
